# Benchmark Notes

MindGraph does not yet have a formal benchmark suite or published results.

When benchmark work is added, record:

- machine and operating system
- JDK version and vendor
- build mode (e.g. `./gradlew build` vs. a packaged native distribution)
- exact command being measured
- input size or dataset shape (e.g. note/link count for graph layout performance)
- number of runs and the raw results

Prefer keeping benchmark methodology stable so future comparisons stay meaningful.
